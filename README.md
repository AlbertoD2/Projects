# Projects

- [Dream2.io](https://github.com/AlbertoD2/Dream2.io) — Personal website; collections of digital, visual, and written work.
- [MarkupShot](https://github.com/AlbertoD2/MarkupShot) — Local-only macOS app for capturing windows and adding numbered annotations to share precise visual feedback with AI agents or teammates.
- [Ceramic](https://github.com/AlbertoD2/Ceramic) — Offline macOS workspace for client relationships, engagements, activity plans, hours and documents, backed by a local Excel workbook.
- [Fyord](https://github.com/AlbertoD2/Fyord) — Offline macOS menu bar app for staging files, clipboard captures, bookmarks and voice notes, with local OCR and a running list.
- [NoteArchiver](https://github.com/AlbertoD2/NoteArchiver) — Native macOS SwiftUI app for previewing Apple Notes and exporting selected notes to PDF or plain text with a ZIP archive.
- [Polyrow](https://github.com/AlbertoD2/polyrow) — Native macOS research spreadsheet for gathering, scoring and ranking information, with an MCP server that lets AI agents read and add findings.
